SMTP responses

One page per response you actually see in a log: what it means, whether retrying helps, and what to change so it stops.

4.7.284xx Gmail: unusual rate, deferred not blocked

A throttle, not a block. Slow down for Gmail specifically and the mail still goes.

 5.7.15xx Gmail: message blocked for reputation

A hard reputation block. Stop sending from this IP or domain and remediate before resuming.

 5.7.6065xx Microsoft: access denied, banned sending IP

Your sending IP is on Outlook's block list. Delist, then fix what caused it.

 5.1.15xx Recipient address does not exist

Permanent. Suppress it, because retrying costs reputation.
